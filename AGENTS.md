# MFA viewer repository instructions

- This repository contains the public static viewer for the `aimesy/mfa-data` release of California impact fee collections.
- Keep release files out of this repo. `aimesy/mfa-data` is private: the viewer reads the CSV, `sources/index.csv`, `evidence/index.json` and `manifest.json` at run time through the Cloudflare Worker at `https://mfa-data.amyc.us/<sha>/` (source in `worker/`, described in the README), and the evidence PDFs and reports, which are release assets, from the same Worker at `/releases/download/<tag>/<name>`. The Worker holds a GitHub token that can read that repository's contents and nothing else. Never put a token in this repo or in the page. The Worker's default entrypoint (origin check, Turnstile session, the flood guard for each address and the document limits in `worker/gate.js`) must stay uncached; only `Release` is cached. `worker/gate.js` and `worker/gate.contract.mjs` are the canonical copies of the files every data Worker carries (aimesy/kcsc, nysc, tentatives, sfsc); change them here and copy them across. The site offers no bulk document downloads, and the static pages `seo/build.mjs` writes for search engines carry no dollar amounts. `check-static.mjs` fails if the viewer reaches GitHub directly or if the Worker's `RELEASE_PATH` or `ASSET_PATH` differs from the viewer's.
- Do not write to `aimesy/mfa-data` from here. Its release pipeline is the only writer to `main` and owns `manifest.json`, `validation/`, `README.md`, `docs/` and `data/`.
- The shared theme loads live from `https://aimesy.github.io/themes/src/` (the test-gated Pages copy of `aimesy/themes`), so a theme merge reaches this site without a change here. Do not pin it to a commit or load it from jsDelivr; `check-static.mjs` requires each of the five assets in `index.html` exactly once from that URL.
- Release text reaches the DOM through `textContent` or attributes only. `check-static.mjs` fails on `innerHTML` and similar calls.
- pdf.js 4.10.38 is vendored in `vendor/`. Keep `isEvalSupported: false`.
- Tag symbols are drawn in black and white from the whole Noto Emoji face in `vendor/noto-emoji/` (Google's unicode-range subsets; a page loads only the ones it uses). Put symbols in a `.sym` span with U+FE0E so they never fall back to a colour emoji font.
- Sum primary rows only (`is_primary_in_figure_group`). A missing program-year is missing, never zero.
- `lib/fee-links.js` joins fee program names into one fee for display only. Add a link only with evidence from the reports (matching closing and opening balances, a reprint of the old figures, or a difference in wording alone) and record it; `tests/model.test.mjs` fails on a link the release no longer matches.
- Draw a box from `outline_rect_pdf_points` only after it is confirmed against the red outline in that figure's evidence file; otherwise draw none and say why.
- The limits protect the documents (the evidence PDFs and reports), not the data. Scraping the data rows is acceptable; mass downloading of documents (thousands, not a reader's hundred) is what the gate stops. Every amount, sum and row stays visible without opening anything, and only `documentKey` in `worker/release.js` decides what counts. Do not meter, withhold or blur data rows to slow scraping.
- The Download menu's CSV and HTML report carry data rows only, never PDFs or Worker document URLs (approved by Amy on 2026-11-06). Their links go to `https://mfa.amyc.us/` and the publisher's own copy.
- Every list filter is a `lib/filter-box.js` box: several values joined with `|`, each part checked when the URL is read, counts from the tab's other filters. Lib views take the box helpers and the district filter from `libCtx()` in `app.js` (the comment above it lists each one); keep `ctx.select` and `ctx.chip` working for views that still use them. A lib view hands its rows to the Download menu and the report through an exported function (`exportFunds`, `exportSchedules`, `exportPermits`) that `app.js` calls with a ctx built from the address bar, so a tab never opened can still be downloaded or reported.
- Every `lib/*.js` loads through the import map in `index.html`, keyed with the same `?v=` as `app.js` and `styles.css`. A new lib file, or a key bump, changes the map, so recompute its `sha256` in the CSP's `script-src`; `check-static.mjs` fails until the map, the key and the hash agree.
- `legislative/districts.json` is read from this site on demand (a district box, filter, page line or the Districts tab), never through the Worker. Wherever results are filtered by district, show its overlap caveat and label sums as whole-agency sums: an agency counts in full in every district it touches.
- Run `node check-static.mjs`, `node tests/model.test.mjs` and `node tests/worker.test.mjs` before pushing. Use the authorized browser control tool for browser QA when the panel, loading or layout changes.
